# DeX Gamepad Fix 1.0

Экспериментальный workaround для Samsung DeX / One UI 8, когда Bluetooth-геймпад теряет аналоговые оси после выключения экрана телефона.

## Что делает эта версия
- сохраняет текущий SCREEN_OFF_TIMEOUT;
- ставит максимально большой таймаут;
- по кнопке OFF возвращает исходное значение.

Это намеренно простая версия без Shizuku: сначала проверяем, достаточно ли не допускать обычного screen-off на конкретной прошивке S21 FE.

## Сборка
Открыть папку DexGamepadFix в Android Studio, дождаться Gradle Sync и выбрать Build > Build APK(s).

## Первый запуск
1. Нажать «Разрешить изменение настроек» и разрешить DeX Gamepad Fix.
2. Нажать «Включить FIX».
3. Для DeX по USB-C включить в «Для разработчиков» параметр «Не выключать экран во время зарядки» как дополнительную страховку.
4. Проверить геймпад в DeX.
5. После теста нажать «Выключить FIX».

Если эта версия не помогает, следующий вариант должен использовать Shizuku/UserService и системный power service, поскольку обычный FLAG_KEEP_SCREEN_ON работает только у foreground Activity.
